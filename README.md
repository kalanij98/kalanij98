## 🏥 Featured Project — India Healthcare Clinic Finder

> **AI-powered B2B lead research tool · Python + Claude API · Freelance delivery**

A client needed verified contact data for independent medical clinics
across Indian cities — 26 specialties each — with phone numbers,
GPS coordinates, and doctor names.
Manual research was taking days per city.

I built a Python tool that:
- 🔍 Searches Google Maps, JustDial, Practo & Lybrate via Claude's live web search
- 🚫 Filters 25+ corporate chains by name, address AND IVR phone pattern
- 🧠 Reads review text to detect and exclude fraud / malpractice clinics
- ♻️ Deduplicates strictly — same phone number never appears twice
- 📊 Exports colour-coded Excel with one sheet per specialty

**Result:** Days of manual work → under 2 minutes per search ⚡
